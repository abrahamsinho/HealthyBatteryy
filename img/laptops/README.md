# Imágenes de laptops

Coloca aquí una imagen PNG para cada modelo ASUS. Usa exactamente estos
nombres para que el simulador las encuentre automáticamente:

- `asus-vivobook.png`
- `asus-zenbook.png`
- `asus-expertbook.png`
- `asus-proart.png`
- `asus-tuf.png`
- `asus-rog.png`

La imagen aparece en el panel "Equipo y batería". Se recomienda una imagen
nítida con fondo transparente o claro; mientras no exista, el simulador
mostrará la ilustración del equipo.
