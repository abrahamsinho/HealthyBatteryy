# Imágenes de celulares

Coloca aquí una imagen PNG para cada modelo. Usa exactamente estos nombres para
que el simulador las encuentre automáticamente:

- `iphone-11.png`
- `iphone-12.png`
- `iphone-13.png`
- `iphone-14.png`
- `iphone-15.png`
- `iphone-16.png`
- `iphone-17.png`
- `iphone-18.png` (iPhone 18 Pro)

La imagen aparece recortada dentro de la pantalla ilustrada del modelo en el
panel "Equipo y batería". Se recomienda una imagen vertical y nítida; el
simulador mantiene su ilustración si todavía no encuentra la foto
correspondiente.
